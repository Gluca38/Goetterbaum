# Daten von Anfang an einer Firma zuordnen

Heute nutzt nur eine Firma die Software, perspektivisch sollen aber fremde Firmen dazukommen. Deshalb gehört jeder Kunde, jedes Objekt, jeder Mitarbeiter und jeder Zeiteintrag schon jetzt zu einer Firma, auch wenn es nur eine gibt und davon in der Oberfläche nichts sichtbar ist. Ein nachträgliches Aufteilen bestehender Daten auf Firmen wäre teuer und fehleranfällig; die stille Vorbereitung kostet jetzt wenig.

## Considered Options

- **Später umbauen**: am Anfang schneller, aber jede Tabelle und jede Abfrage müsste nachträglich angepasst und alle Bestandsdaten migriert werden, mit dem Risiko, dass Daten zwischen Firmen sichtbar werden.
