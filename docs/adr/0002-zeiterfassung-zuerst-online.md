# Zeiterfassung setzt zunächst Internet voraus

Die Live-Erfassung (Start/Stopp) funktioniert vorerst nur mit Internetverbindung; fehlt sie vor Ort, trägt der Mitarbeiter die Zeit später als Nachtrag ein. Eine Offline-fähige App ist deutlich aufwendiger (Zwischenspeichern im Handy, spätere Übertragung, Konflikte bei Gerätewechsel) und wird erst nachgerüstet, wenn fehlendes Netz im Alltag tatsächlich häufig stört.
